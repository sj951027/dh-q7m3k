## 어떻게 + 검증
- 삽입분 ASCII only, 파일 기존 개행(LF) 유지, goto/라벨 미사용(LF 파일 라벨 호환성 회피).
- **fail-open 설계**: GUARD_DOW=9/GUARD_HH=99 센티널 기본값 → powershell 실패·FORCE_RUN
  설정 시 조건 불충족으로 실행 허용. 가드 오류로 배치가 죽는 경로 없음.
- 시간 파싱: (Get-Date).Hour / [int](Get-Date).DayOfWeek — 정수 출력이라 "09" 8진수
  오파싱 함정 없음. echo에 %TIME% 직접 리다이렉트 없음(스트림 번호 오파싱 함정 회피).
- 경계 확인(탁상): 월 10:30→차단 / 월 20:10→허용 / 금 01:30→허용 / 토 14시→허용.
- Windows 실행 검증은 미실시(오프라인) — 실측 확인 포인트: 다음 평일 장중 부팅 시
  로그에 "[guard] Blocked" + DB 미적재, 평일 저녁 정상 실행.
