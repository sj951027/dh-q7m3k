## 1. 그래서 뭐가 바뀌나
- 성적표에서 lv_e 행을 누르면 **lv_e 가 오늘 고른 목록**(`lve.html`)이 열린다. 저변동 lv_b 페이지와 같은 틀(오늘 목록·필터·지난 날짜 탭·신선도 배지)이고, 머리말에 "관측 챌린저 · 유의(11/04) · 운용 목록은 lv_b · 교체는 2차 창(≈12/30) 뒤" 를 못박았다.
- 성적표의 lv_e 안내 문구: "목록 탭은 lv_b" → "운용 목록은 lv_b — lv_e 목록은 관측용(lve.html)".
- 상단 메뉴는 그대로(lv_b 가 운용 기준). lve.html 은 성적표 링크·주소 직접 입력으로만 들어간다.

## 2. 왜 바꿨나
- 사용자(11/10): "lv_e 는 왜 html 로 볼 수 있는 게 없지?" — 성적표 1위(h20 IC +0.231) 모델인데 목록을 볼 곳이 없었다. 9/1 가중 0 챌린저로만 등록했고 목록 페이지는 표시 기준(lv_b)에만 배선돼 있었기 때문.
- 운용 목록 교체는 관측 계약(D31, 2차 창 ≈12/30) 뒤에만 — 그래서 **lv_b 페이지를 바꾸지 않고 관측 페이지를 하나 더** 두는 방식.
