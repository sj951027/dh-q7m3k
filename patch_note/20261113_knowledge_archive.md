## 2. 왜 바꿨나
- 사용자(11/13): "지식 세 장 압축하면 되는 건가? 구조 개선을 더 할 수 있나? 계속 쌓고 잘 정리하고 지속적으로 발전하고 똑똑해졌으면."
- 이번 주에 실제로 겪은 것 네 가지가 근거다.
  1. 세 장이 모두 상한 근처라 새 결론을 적을 자리가 없었고, 압축은 곧 삭제라 손이 안 갔다.
  2. 11/10 에 이미 있는 번호(K33·K40)로 새 행을 넣으려다 두 번 막혔다.
  3. sv_b 가 판정 조건에 도달한 것과 11/3 에 써 둔 Codex 판정 요청서가 있다는 것을 세션 시작에 아무것도 알려 주지 않았다(오늘 새 알림이 그 요청서를 바로 찾아냈다).
  4. heredoc 실패를 네 번(10/20·11/8·11/10·11/13), python 일괄 종료 시도를 두 번 반복했다 — PITFALLS 의 "두 번 당하면 규칙으로 올린다"를 실행.
- 기대 기록의 근거: 11/10 계획서에 "사건 뒤 5일은 +5%p 를 넘기 어렵다"고 적었는데 신탁 체결이 넘었다. 가격 밖 정보를 과소평가하는 버릇이 한 번 드러났고, 이런 어긋남을 모으면 다음 실험을 고르는 눈이 좋아진다.
