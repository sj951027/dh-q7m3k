## 왜 바꿨나
- `leaderboard.py verdict()` 는 IC < −0.03 이면 **구간이 0을 걸쳐도** '역작동'을 찍는다(코드 259행). 실측: lv_a IC −0.034, 95% 구간 [−0.087, +0.020] → 자동 라벨 '역작동', 정본(8/29)은 '노이즈'. v30 도 자동은 '기움'(Bonferroni 보류)인데 정본은 '유의'. 같은 페이지에 두 라벨이 나란히 있어 읽는 사람이 헷갈린다(9/18 메모 보류 항목).
- 라벨은 §11 정본(VERDICT → `models_registry.json` → 페이지 SEALED)만 쓰고, 자동 계산은 숫자로만 보이는 게 "자동/정본 구분" 원칙에 맞다.
