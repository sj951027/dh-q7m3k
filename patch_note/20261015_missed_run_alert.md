# 2026-10-15 — 배치가 안 돈 거래일을 텔레그램으로 알림 (2026.10.24 · 표시 전용 · 점수·판정 0-diff)

## 그래서 뭐가 바뀌나
- 배치가 하루 건너뛰어졌으면, **그다음 배치의 텔레그램**에 한 줄이 붙고 첫 줄이 '확인 필요'가 된다:
  `⚠️ 배치가 안 돈 거래일: 10/14 — 그날 점수·판정 앵커 없음(PC 재시작 뒤 로그인 안 됨 등 · 일부러 건너뛴 날이면 skip_dates.txt 에 적기)`
- 같은 빠진 날은 한 번만 알린다(직전 run 과 이번 run 사이만 보므로). 오늘(10/15) 저녁 배치가 10/14 를 처음 알릴 예정.

## 왜 바꿨나
- 10/14(화) 20:10 배치가 통째로 안 돌았는데(기록 파일도 건너뜀 표시도 없음) 아무 알림이 없어 다음 날에야 알았다. 종전에는 일요일 주간 요약(최근 7일 run 확인)에서나 보였다.
- 원인(Windows 기록으로 확인): 10/14 04:19 Windows 업데이트(TrustedInstaller)가 컴퓨터를 재시작 → 배치 예약(`dh-q7m3k-daily`)이 '로그인되어 있을 때만 실행'(Interactive) → 20:10 에 로그인 안 된 상태라 '놓친 실행 1'. '업데이트 후 로그인 정보로 자동 설정 완료'는 이미 켜져 있었는데도 자동 로그인이 안 된 것으로 보인다(이유는 확인 못 함 — 'Windows Hello 로그인만 허용'이 켜져 있으면 이 기능이 비밀번호를 쓰지 못한다는 것이 유력한 추정).
- 빠진 날의 점수는 되살릴 수 없다(다음 날 장중을 지나면 재실행이 그날 자료가 아니게 됨) — 그래서 막기보다 **빨리 아는 것**을 먼저 넣었다.
