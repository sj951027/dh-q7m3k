# 2026-09-22 — 종가 정정 감시에 종목별 상세 기록 추가(측정만·실패 격리) (2026.09.23 · 판정·점수·적재 동작 0-diff)

## 그래서 뭐가 바뀌나
- 시세 수집(`universe_ohlcv.py`)이 재확인 창에서 "이미 저장된 종가 ≠ 방금 받은 종가" 를 발견하면, 종전 요약(`logs/close_revisions.csv`: 날짜별 건수·최대 변화%)에 더해 **종목별 상세**를 `logs/close_revisions_detail.csv` 에 누적한다.
  열: `run_started_at(수집 시작 시각), observed_at(그 종목을 실제 조회한 직후 시각), target_date, ticker, old_close, new_close, pct`. 두 시각을 나눈 이유: 수집이 7분쯤 걸려 종목마다 조회 시각이 달라, 값이 언제 바뀌었는지 보려면 종목별 시각이 필요(Codex 검토 3). 로그에 "상세 기록 N행 → close_revisions_detail.csv (요약 건수 대조: 일치/불일치)" 한 줄.
- 로그 문구 정정: 0건일 때 "전날 수집값이 공식 종가와 같았다" → **"재확인 범위에서 감시 조건에 해당하는 종가 변경 0건(±5% 초과 재조정은 별건)"**(감시가 못 보는 범위가 있으니 단정 금지). 5건 이상 경고도 "애프터마켓 가능성" 단정 대신 "원인 미확정 — 상세 기록으로 확인".
- 적재 동작·저장 값은 그대로다. 상세 기록이 어떤 이유로든 실패하면 경고 한 줄만 남기고 수집·적재는 계속된다.
