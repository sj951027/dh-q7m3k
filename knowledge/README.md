# knowledge/ — 결론 카드 (2026-11-15 시작 · K42 부터)

**왜**: `KNOWLEDGE.md` 한 행에 숫자·근거·한계를 다 넣는 방식은 일주일 만에 상한에 닿았다. 새 결론은 **카드 한 장(상세) + `KNOWLEDGE.md` 한 줄(색인)** 으로 쓴다. 옛 행 K01~K41 은 그대로 두고, 12월 말 판정 3건이 끝난 뒤 판정과 무관한 분야부터 옮긴다(`research/DESIGN_20261115_knowledge_scale.md` §7).

## 규칙
- 파일 이름 `K##.md`(번호는 세션 시작 알림의 '다음 번호'). **번호 하나의 현재 결론은 한 곳에만** — 카드가 있으면 `KNOWLEDGE.md` 에는 색인 한 줄만 두고 내용을 고칠 땐 카드를 고친다.
- `KNOWLEDGE.md` 색인 한 줄(표의 같은 열에 맞춰): `| K## 자리 | 축 | 한정된 결론(대상·지평 포함) | 대표 숫자 하나 + n | 상태 · 재검 조건 한마디 | knowledge/K##.md |`
- 카드는 정본을 **대체하지 않는다** — 정본(연구 메모·판정문·사전등록)으로 가는 입구다. 숫자를 인용할 땐 카드를 열고, 판정·등록 문서는 정본에서 직접.
- 한 카드에 축이 여럿이면 **축마다 상태를 따로** 적는다(한 줄로 뭉개지 않는다).
- 줄이거나 바꿀 때 옛 문장은 카드의 '이력'에 남긴다(보관소로 옮길 필요 없음).

## 양식
```markdown
# K## — 축 이름 (자리 ①~⑦ 또는 자료·운용)

- 상태: 열림 / 닫음 / 관측 중 / 대기   · 결론 종류: 실증 / 규약 / 대기
- 결론(한정해서): 무엇이 · 어느 대상·지평에서 · 어땠다
- 비교 기준: 무엇과 견준 값인가   · 진입·측정 시점:
- 근거: n · 효과 [95% CI] · 기간 · (대리인지 실제 목록인지)
- 독립 재현: 있음(누가·어디) / 없음
- 적용 범위·오독 방지: 이 결론이 말하지 않는 것
- 재검 조건: 무엇이 오면 다시 여나(충족 = 재검토 시작이지 채택이 아님) · 관련 약속 P##
- 정본: 경로(절)   · 근거 확인일: YYYY-MM-DD
- 관련: 반례 K## · 의존 K## · 설계가 달라 비교 못 함 K## · 대체한 번호 K##
- 꼬리표: 낱말 몇 개(`WHERE.md` 의 낱말과 맞춘다)

## 실험 끝 세 줄
- 예상과 다른 점:
- 겉보기 반례:
- 설계가 달라 비교 못 하는 점:

## 이력
- YYYY-MM-DD 처음 씀 / 고침(무엇을 왜)
```
