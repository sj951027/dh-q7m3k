읽고 시작하는 가이드

이 종목들은 어떻게 골라졌고, 화면의 등급·숫자를 어떻게 읽나

이 화면의 종목은 “사라”는 추천이 아니라 여러 안전장치를 통과한 관찰 후보입니다. 어떤 깔때기를 거쳤는지, 등급·점수가 무슨 뜻인지 알고 보면 훨씬 정확하게 활용할 수 있어요. 맨 끝의 “한계” 단락을 꼭 읽어주세요. (투자 권유가 아닙니다.)

1한눈에 보는 깔때기

상장 전체 ~768 └─ 금융주·리츠·스팩 제외 → ~700 └─ ① 과매도 점수화 + 매집·추세·수급·레짐 (많이 빠졌나? 큰손이 받나?) └─ '떨어지는 칼날'(추세 하락 지속)은 패널티/제외 └─ ② DART 공시 위험필터 안전 / 주의 / 위험 (가짜 악재 방어) └─ ③ 펀더멘털(영업이익 YoY) + 현금흐름 질(OCF) └─ ④ v3 재점수 → 등급·버킷 ← 화면에서 보는 것 └─ ⑤ 섹터 쏠림 방지(업종당 최대 N) └─ (참고) ⑥ 관측 팩터: smartmoney·ROE·자사주소각 (점수 미반영)

즉 “많이 빠졌고(과매도) → 망할 신호는 없고(공시 안전) → 실적·현금흐름이 받쳐주고 → 반등 조짐이 보이는” 종목을 추려, 한 업종에 몰리지 않게 정리한 목록입니다. (숫자는 어느 날 KOSPI 예시)

2각 단계가 무엇을 걸렀나

① 과매도 + 매집/추세/수급/레짐

  • 과매도: RSI(낮을수록)·볼린저 하단 근접·52주 고점 대비 낙폭·이동평균선 이탈·스토캐스틱을 종합.
  • 수급: 외국인·기관 최근 5일 순매수. 특히 많이 빠졌는데(−10%↑) 큰손이 사들이면 가점.
  • 떨어지는 칼날 방어: 5일 저점 부근 + 5일선 < 20일선 + 양봉 없음이면 추세 하락으로 보고 강하게 깎거나 제외.

② DART 공시 위험필터 — 거래정지·관리종목·감사의견 부적정·횡령/배임·자본잠식·상장폐지 사유 등 위험 키워드를 검사 → 안전 / 주의 / 위험. 단순 “거래정지해제”·액면병합 같은 중립 공시는 가짜 악재 방어로 안전 처리.

③ 펀더멘털 + 현금흐름 질(OCF) — 영업이익 패턴(턴어라운드/흑자전환/성장지속/관망/하락지속/피크아웃) + 현금흐름(현금창출양호…밸류트랩의심=흑자인데 현금 적자, 이중적자=위험).

3화면에서 먼저 볼 것 — 버킷과 등급

버킷(bucket) — 지금 어떻게 대하면 되나

버킷뜻보는 법
BUY품질·반전·수급·실적이 모두 기준 통과 (A·A+)가장 강한 후보. 그래도 차트·공시 직접 확인
WAIT품질 좋고 반전이 어느 정도 확인 (B, 반전≥4)반등 확인되면 BUY로 올라올 대기 후보
OBSERVE후보군이나 신호가 아직 약함 (B/C)지켜보는 단계
WATCH주의 공시 또는 밸류트랩의심점수와 별개로 경계 — 원문 확인 권장
EXCLUDE위험 공시 / 떨어지는 칼날 / 이중적자사실상 배제 (점수 −999)

등급(grade) — 얼마나 엄격한 기준을 통과했나 (A+ < A < B 순으로 조건이 느슨해짐)

  • C: 후보지만 품질 점수가 낮음 / 기타.
  • B: 메인후보 + 품질 ≥ 12.
  • A: 품질 ≥ 15, 반전 ≥ 8, 수급 ≥ 0, 턴어라운드 ≥ 0, 최종점수 ≥ 35 (밸류 데이터 있으면 저평가 ≥ 12도).
  • A+: 가장 엄격 — 품질 ≥ 18, 반전 ≥ 8, 수급 ≥ 8, 턴어라운드 ≥ 5, 최종점수 ≥ 50, 공시 ‘안전’ (밸류 ≥ 15).
  • WATCH / EXCLUDE: 주의·위험·밸류트랩·이중적자에서 강등·배제.

4final_score_v3 는 무엇으로 이뤄지나

6요소의 합이며 가중치는 현재 전부 1.0. 위험/칼날/이중적자는 −999로 바닥 처리합니다.

요소범위무엇을 보나
반전 reversal0~155일선 회복·3% 반등·거래량 동반 양봉·단기 개선 = 바닥 다지는 신호
수급 supply−10~15(외인+기관 5일 순매수) ÷ 20일 평균거래대금 강도. 양쪽 다 사면 보너스
품질 quality−25~25OCF 흑자·전환율(0.7~5배)·분기/연간 YoY·현금흐름 패턴
턴어라운드−15~20영업이익 패턴(턴어라운드/흑자전환 +12 … 피크아웃 −15) + 분기 YoY 급증
밸류 value0~25업종 내 PBR/PER 백분위(쌀수록↑). 오프라인이면 0
과매도 oversold최대 20“많이 빠졌다”는 후보 자격일 뿐 → 비중을 일부러 작게

진입 점수(entry_score)는 같은 후보 중 지금 타이밍을 보려고 반전·수급에 더 큰 가중을 준 별도 점수입니다. 등급·버킷이 먼저, 최종점수는 그 안에서의 정렬용으로 보세요.

5같이 보면 좋은 보조 표시

  • 시장 레짐(강세장/조정장/약세장) = 지수 + 환율(USD/KRW) + 외국인 흐름 종합 = 그날 전체 분위기. 단, 그날 모든 종목에 똑같이 적용되어 같은 날 종목 간 순위에는 영향이 없습니다(맥락·표시용).
  • 다이버전스 = 한 달 −10% 이상 빠졌는데 외국인/기관이 사들이는 종목. “남들 팔 때 큰손이 받는” 후보.
  • 관측 팩터(smartmoney · ROE · 자사주 소각) = 예측력 검증용으로 따로 쌓아두는 참고 지표. 지금 등급/점수에는 들어가지 않습니다.

⚠️ 숫자를 해석할 때 꼭 알아둘 한계

  • 점수는 “덜 위험한 후보를 추리는” 데 강하고, BUY 안에서의 미세 순위 예측력은 사실상 0에 가깝습니다. 등급/버킷을 “확률 높은 한 방”이 아니라 “걸러진 관찰 후보군”으로 받아들이세요. 1등이 2등보다 꼭 더 오른다는 뜻이 아닙니다.
  • 과매도 = ‘싸다’가 아니라 ‘많이 빠졌다’. 추세 하락 종목이 섞일 수 있어 필터를 두지만 완벽하지 않습니다.
  • 데이터는 지연됩니다. 재무는 분기 공시, 밸류에이션(PBR/PER)은 보통 전 거래일, 수급은 최근 5일 합산 기준.
  • 검증 표본이 아직 적습니다. 적중도(IC) 카드가 “데이터 쌓는 중”이면 점수의 실효성은 아직 통계적으로 확정되지 않은 상태입니다.
  • 공시 필터는 키워드 기반이라 오탐/누락이 있을 수 있습니다 → 중요한 종목은 DART 원문을 직접 확인하세요.
  • 투자 판단 보조용이며, 투자 권유가 아닙니다. 모든 결정과 책임은 본인에게 있습니다.

6추천 사용 순서

  • 버킷 BUY → WAIT 부터 본다 (OBSERVE/WATCH/EXCLUDE는 후순위).
  • 관심 종목은 차트 + DART 원문 + 최근 실적을 직접 확인한다.
  • 🧭 섹터 분산 토글로 한 업종 쏠림이 아닌지 점검한다.
  • 다이버전스/수급으로 “큰손이 받는지”를 보조 확인한다.
  • 시장 레짐으로 그날 전체 분위기(공격적/신중)를 감안한다.
