§11 판정 규칙 — OOS 40거래일 미만은 숫자가 좋아 보여도 무조건 노이즈(표본 부족 기본값). 트랙 간 IC 절대값 비교 금지(유니버스가 다름). h=20d가 주지표, h5는 보조.
용어 설명 (IC · h20 · n · OOS · 95%CI · 판정)

IC — 그날 매긴 점수 순위와 이후 실제 수익률 순위의 일치도(스피어만 상관). +1=점수 순서대로 올랐다, 0=무관, 음수=거꾸로. +0.05면 쓸만, +0.1↑면 강한 편.

h20 / h5 — 몇 거래일 뒤 수익으로 채점했나. h20=20거래일(≈한 달, 주지표), h5=5거래일(보조). h10 / h3 / h1은 참고용 관측 — 신생 모델도 숫자가 빨리 차지만(짧을수록 노이즈↑) 판정에 안 쓴다. h10은 h5↔h20 사이 다리 역할(특히 h20이 아직 빈 lowvol·wu).

n — IC를 계산할 수 있었던 날짜 수. 최근 회차는 아직 미래 수익이 확정 안 돼 n에 안 들어간다.

OOS — 모델 등록(스펙 동결) 이후 지나간 거래일 수. 등록 전 데이터로 잰 건 인샘플이라 제외. 40일이 차야 판정 자격.

95%CI — 부트스트랩(2,000회)으로 추정한 "진짜 IC가 있을 범위". n이 작을수록 넓다. 구간 전체가 0보다 위여야 우연이 아니라고 볼 최소 요건.

판정 — OOS≥40 + CI>0 + 주간 방향 일관성 60%↑ + 다중검정 보정 통과 = 유의, 경계면 기움, 그 외 노이즈.
