# pitfalls/ — 함정 상세 (2026-11-27 시작 · D52)

**왜**: `PITFALLS.md` 한 장(상한 5KB)에 함정을 전부 한 줄씩 넣는 방식은 자리가 109B 까지 줄었다. 상한은 올리지 않고(D52) **어느 세션에서나 걸릴 수 있는 것만 `PITFALLS.md` 에 짧게**, 상세와 분야별 함정은 이 폴더의 주제 파일에 둔다.

## 규칙
- 주제 파일은 넷: `tools.md`(도구·git·배치·배포) · `data.md`(자료 한계) · `method.md`(연구 방법·판정) · `records.md`(기록·지식 장·검사 장치). 새 주제 파일을 만들면 `PITFALLS.md` '분야별' 표에 한 줄 — 검사 장치(`tests/test_knowledge_sheets.py` [6])가 표에 없는 파일을 막는다.
- 한 줄 = 함정 · 증상 · 피하는 법 · 날짜. **실제로 당한 것만**(추측 금지).
- 새 함정: ① 맞는 주제 파일 맨 아래에 원문 한 줄 ② 어느 세션에서나 걸릴 수 있으면 `PITFALLS.md` '항상'에도 짧은 한 줄(피하는 법이 빠지지 않게) ③ 분야별이면 `PITFALLS.md` 표의 낱말 칸에 낱말 하나.
- 같은 함정에 두 번 당하면 `CLAUDE.md` 로 올린다. 더는 안 일어나는 줄은 지운다(지울 땐 `KNOWLEDGE_ARCHIVE.md` 로 옮긴다).
- 주제 파일에는 크기 상한이 없다 — 매 세션 읽지 않기 때문이다. 그 분야 일을 시작할 때 읽는다(`WHERE.md` 가 가리킨다).
