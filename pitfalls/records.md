# pitfalls/records.md — 기록·지식 장·검사 장치

**읽을 때**: 세 장·카드·결정 이력을 고치거나 hook·검사 장치를 만질 때. `PITFALLS.md`(매 세션 읽는 한 장)의 상세다 — 한 줄 = 함정 · 증상 · 피하는 법 · 날짜. **실제로 당한 것만**. 새 함정은 맨 아래에 덧붙이고, 어느 세션에서나 걸릴 수 있으면 `PITFALLS.md` '항상'에도 짧은 한 줄. 더는 안 일어나는 줄은 지운다.

## 2026-11-27 에 `PITFALLS.md` 에서 옮긴 줄 (글자 그대로)
- **세션 중간에 만든 hook(`.claude/settings.json`)은 그 세션엔 안 실린다** — 새 세션이나 긴 문맥 뒤 resume 부터(11/8 실측). 시나리오 시험 통과 ≠ 실림 확인.
- **면제·예외 문자열을 문서 설명에 그대로 쓰면 장치가 그걸 진짜 선언으로 읽는다** → 선언은 독립된 한 줄만 인정, 설명엔 백틱. 11/8.
- **지식 ID 는 세션 시작 알림의 '다음 번호'를 쓴다**(겹치면 테스트가 막는다). 11/10.
- **줄여서 묶을 때 '지킬 값'이 빠지면 숨는다**(D10 '비우기는 사용자'·D24 '전 거래일 종가'가 보관소에만 남아, 기억 없는 시험에서 검색으로만 찾음) → 묶음에는 이름이 아니라 지킬 값을 남긴다. 구현 끝 ≠ 효력 끝. 11/15.
