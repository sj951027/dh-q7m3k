# worklog/ — 세션 작업 기록 (2026-10-03 도입)

새 세션이 **이전 세션에서 무엇을 왜 어떻게 했는지** 이어받기 위한 기록이다.
패치노트(`patch_note/`)는 "무엇이 바뀌었나"를 변경 건별로 적고, 여기는 **세션 한 번의 흐름**을 적는다:
무엇을 요청받았나 → 무엇을 확인했나 → 무엇을 정했나(사용자 결정) → 무엇을 바꿨나 → 무엇이 남았나 → 다음엔 어디서 시작하나.

## 새 세션이 시작할 때
1. 아래 목록에서 **가장 최근 기록 1건**을 끝까지 읽는다(특히 "다음 세션 시작점"과 "남은 일").
2. 필요하면 그 기록이 가리키는 패치노트·연구 문서만 골라 읽는다.
3. 기록과 실제(코드·git 이력)가 다르면 실제가 맞다 — 기록을 고친다.

## 세션을 마칠 때
- 코드·화면·운영·결정이 하나라도 있었으면 `worklog/YYYY-MM-DD_주제.md` 1건을 쓴다(연구만 한 날도 결론 한 줄은 남긴다).
- 아래 목록 맨 위에 한 줄 추가한다.
- 양식(순서 고정): **요약 → 시간순 흐름 → 사용자 결정 → 바뀐 것(커밋·파일) → 검증 → 남은 일 → 다음 세션 시작점 → 작업 요령(이번에 배운 것)**.
- 쉬운 말로, 실측과 추정을 구분해서. 비밀·토큰·개인 매매 수치는 적지 않는다.
- PTW(`../Position-Tracker-Web`) 작업도 같은 기록에 함께 적는다(두 저장소가 한 세션에서 같이 움직인다).
