- 배치 래퍼(`.bat`)는 사본에서 마지막 실행 줄만 바꿔 시험한다(실제 배치를 돌리지 않고).
- 긴 대기: 백그라운드 명령은 10분에 끊긴다 → `Monitor`(30분, 만료 시 다시 걸기). 종료 표식은 정확한 문구로(`diversified_picks_*.csv` — 느슨하면 오탐).
- 화면 확인: `python -m http.server` 로 `docs/` 를 띄우고 내장 브라우저로 본다. 파일 직접 열기(file://)는 스크립트가 안 돈다.
- PTW 화면은 `index.html` 에 가짜 `fetch` 를 끼운 하네스로 확인한다(로그인은 하드 경계).
- PTW 커밋·푸시는 이 환경의 자동 검사에 막힌다(운영 배포로 분류) → 사용자가 GitHub Desktop 으로. 스크리너 문서 푸시는 됐다.
- 토큰·비밀번호를 화면 입력란에 넣는 일은 Claude 가 하지 않는다 → 사용자가 붙여넣고, 나머지(주소 정리·화면 준비·확인)는 Claude 가 한다.
- `build_scoreboard.py`·`build_dashboard.py` 는 표시 전용이라 직접 돌려도 된다(docs 가 바뀜). `leaderboard.py` 는 돌리지 않는다(docs 를 덮어씀).
- 사용자가 헷갈린 표현: 시장 대비 `%p` 를 수익처럼 읽음 → 수익은 `%`, 차이는 "시장보다 +x%p"로 풀어서.
