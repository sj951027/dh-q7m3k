## 4. 표기 규칙 추가(승인 시 VERDICT_RULES 로)
1. **MDE**: 닫음·보류·판정문에 "이 n·구간으로는 ±x%p 미만은 못 본다"고 쓰지 않는다. 대신 "**95% 구간 폭 = y%p, 실용적 δ 는 미정 → MDE 확인 못 함**" 으로 적는다(δ 와 검정력 모의시험은 처방 ⑤에서).
2. **기대 국면 칸**: **다음 신규 사전등록부터** "A(급락 뒤)에서 강해야 / 국면 무관해야 / 미정" 중 하나를 적고, 판정문 §2 에서 맞았는지 적는다(라벨 불사용). 기존 모델엔 참고 가설로만 — 조건 추가 금지.
3. **결손일**: 판정문 §0 에 "창 안 run 없는 날"을 **완결 범위 안/밖**으로 나눠 적고, 안이면 "그 날 앵커가 없어 영향 크기·부호 확인 못 함"으로(11/4 lv_e 교정 선례).
4. **자리바꿈 통과율**: 어느 조건까지 묶은 통과율인지(h20만 / +Bonf / +주블록 / +h10·짝)를 항상 붙인다.
5. **연구 결론의 상태**: 지도 §10·§12 에서 정정된 옛 숫자를 인용하지 않도록, 정정이 있으면 원문 줄에 "(정정 → …)" 을 단다.
