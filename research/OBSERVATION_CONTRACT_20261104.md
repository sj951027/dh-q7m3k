# 다음 관측 계약 한 장 (초안 2026-11-04 — **사용자 승인 전**, 결과를 보기 전에 고정)

> 지위: 진화 검토 2차 합의(`handoff/CLAUDE_20261104_evolution_round2_merge.md` §3 ①)의 첫 산출물. 승인되면 `VERDICT_RULES.md` 에 "§8 후속 창·관측 계약" 한 절로 옮기고, 여기 적힌 날짜가 정본이 된다. **기존 라벨·분모·주지표·창은 소급 변경하지 않는다.** 이 문서가 정하는 것은 "지금부터 열리는 창과 관측의 결과가 **어느 결정에, 어떤 정의로** 쓰이는가"다.

## 1. 후속 창(2차·3차 창) — 모델 공통 규칙
| 항목 | 규칙 |
|---|---|
| 열리는 조건 | 1차 판정이 **정본**으로 확정된 모델만. 라벨이 '역작동(유의)'(기각)이면 열지 않는다 |
| 시작일 | 1차 창의 **40번째 유효 앵커 다음 run_id**(lv_e: 20261104 run — 11/4 배치 적재분) |
| 종료 | 시작일부터 **유효 앵커 40개** 도달한 다음 배치 뒤 1회 계산(1차와 같은 셈법 ①, 가격 날짜 차 병기) |
| 표본 귀속 | **앵커 날짜**가 창 안이면 그 창의 앵커. h20 완결 앵커만 IC 에 쓴다(1차와 동일). 창 사이 수익 창이 겹쳐도 앵커 기준으로는 비겹침 — 그 사실을 각주 ①에 적는다 |
| 라벨 | 창마다 1차와 **같은 규약·같은 분모**(그 시점 실측 distinct)로 라벨을 낸다. 라벨은 **창별 기록**으로 병기한다("유의(11/4)·2차 ○○(날짜)"). 창 하나의 라벨로 앞 라벨을 지우지 않는다 |

| 결정 규칙(승격·표시 기준) | **"서로 다른 두 판정 창을 모두 거치고, 그중 하나 이상이 '유의' 또는 '기움', 어느 창에서도 '역작동'이 아님"**(§13 2단계 ① — 사용자 11/3 확정 문장) **그리고** §2 돈 관측표에서 상위10 초과의 구간이 0 을 품지 않음(**신규 후보부터** 적용; lv_e 는 참고 병기) |
| 오류율 | 이 절차는 α 를 창 수에 맞춰 보정하지 않는다(규약 불변). 그 대신 처방 ⑤ **절차 모의검증**(겹침·창 수·후보 선택을 넣은 1종/2종 오류 측정)을 하고, 보정이 필요하면 **결과를 보기 전에** 이 문서를 고쳐 다음 창부터 적용한다. 지금 창엔 소급 안 함 |
| 하지 않는 것 | 좋은 창만 골라 보기 · 창 중간에 끝내기 · 시작일 당기기 · 라벨 소급 변경 |

## 4. 표기 규칙 추가(승인 시 VERDICT_RULES 로)
1. **MDE**: 닫음·보류·판정문에 "이 n·구간으로는 ±x%p 미만은 못 본다"고 쓰지 않는다. 대신 "**95% 구간 폭 = y%p, 실용적 δ 는 미정 → MDE 확인 못 함**" 으로 적는다(δ 와 검정력 모의시험은 처방 ⑤에서).
2. **기대 국면 칸**: **다음 신규 사전등록부터** "A(급락 뒤)에서 강해야 / 국면 무관해야 / 미정" 중 하나를 적고, 판정문 §2 에서 맞았는지 적는다(라벨 불사용). 기존 모델엔 참고 가설로만 — 조건 추가 금지.
3. **결손일**: 판정문 §0 에 "창 안 run 없는 날"을 **완결 범위 안/밖**으로 나눠 적고, 안이면 "그 날 앵커가 없어 영향 크기·부호 확인 못 함"으로(11/4 lv_e 교정 선례).
4. **자리바꿈 통과율**: 어느 조건까지 묶은 통과율인지(h20만 / +Bonf / +주블록 / +h10·짝)를 항상 붙인다.
5. **연구 결론의 상태**: 지도 §10·§12 에서 정정된 옛 숫자를 인용하지 않도록, 정정이 있으면 원문 줄에 "(정정 → …)" 을 단다.
