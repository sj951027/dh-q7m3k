# 조건 전면 탐색 — 계산 전 사양

2026-10-04. 사용자가 시장·PER·RSI·모델 점수·수급 등 가능한 많은 조건과 조합을 요청했다. 이전 연구를 본 뒤의 탐색이며 독립 검증·모델 등록이 아니다.

- 동일 패널, 2024-01-02~2026-08-25 목록일, 다음날 시가→20번째 거래일 종가, 왕복0.5%. +20% 종료, 5~20일 종가 도달, 첫날 상승, 최저/최대 낙폭, 경로 결합 목표를 유지한다.
- 코스피·코스닥을 별도로 집계. 가격·추세·RSI·변동성·거래량·시가총액 대리·재무·수급·공매도·신용·컨센서스·저장 모델 점수의 사용 가능성을 조사한다. 식·자료 구간을 모두 기록한다.
- 연속 조건은 같은 날짜·같은 시장의 사용 가능 표본 안에서5등분. 양끝20%를 모든 서로 다른 특성 쌍으로 결합한다. 단변량은5칸 모두, PER/PBR/RSI 등은 절대값 구간도 함께. 빈 칸·짧은 표본도 지우지 않는다.
- 모델 점수는 같은 모델의 기록 집합 안에서만 순위. frozen_at이 해당 목록 다음 거래일09:00(KST)보다 늦은 소급 기록은 제외한다. 과거날짜가 붙었다고 당시 존재한 점수로 보지 않는다. 대형·lead는 원래트랙과 별도이며 미저장 점수는 만들지 않는다.
- 실제 PER/PBR은 valuation_daily 존재기간만. 장기 재무 대리는 저장된 보고서와 항목의 접수번호 날짜 중 늦은 날짜 이후만 사용한다. 최신 보고서 내용을 최초 접수일에 소급하지 않는다. 시총/연간순이익 등 근사와 실제 일별 PER을 구분한다. 당일 공개 시각 불명인 재무는 다음 거래일부터 목록에 사용한다.
- 수급·공매도·신용·컨센서스·일별 밸류는최소1거래일 지연. 과거 기록이 드문 열을 현재 값으로 과거 전체에 채우지 않는다. 결측은0으로 간주하지 않는다.
- 조합 대조는 같은 날짜·시장 및 두 특성값이 모두 존재한 표본. 단일 조건 개선과 두 번째 조건 추가의 개선을 구분한다. 표본 수와 날짜 수, 연도별 결과 모두 저장.
- 전체 조합의 탐색 결과를 남기되, 상세 재추출은 2024~2025 결과로 뽑은 후보의2026 성적과 사용자 명시 조건에 우선 적용한다. 이2026도 이미 다른 연구에서 본 자료이므로 진정한 미사용 검증으로 부르지 않는다.
- 신뢰구간은20일 날짜 블록, 다중 비교를 고려한다. 숫자가 좋은 결과를 기준 완화나 단기 표본 숨기기로 채택하지 않는다.

## 사용자의 범위 확대 요청 반영

초기 양끝 조합 뒤에 중간3구간까지 포함한 모든5×5 조합과 절대구간 조합을 `fullgrid/`에 추가 계산한다. 첫 탐색 결과를 이미 본 확장으로 표시한다. 서로 같은 특성의 중복 교차만 제외한다. 전체 결과는 용량을 줄인 parquet로 저장하며, 표본이0인 조합도 남긴다. 두 번째 조건 추가 효과는 다른 특성이 존재하는 같은 날짜·시장 표본에서 첫 조건만 적용했을 때와 비교한다.
