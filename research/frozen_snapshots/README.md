# 동결 점수 사본

DB 의 동결 점수가 실수로 바뀌었을 때 원래 값을 되찾고, 바뀌었는지 대조하기 위한 사본. `history.db` 를 읽기 전용으로 열어 그대로 뽑은 것(정렬: model_id · market · ticker).

| 파일 | 내용 | 뽑은 때 | sha256 앞 16자 |
|---|---|---|---|
| `lowvol_scores_20261123.csv` | run 20261123 · 1,276행(lv_a·lv_b·lv_e·mom_a·sm_a) · 동결 2026-11-23 20:42:08 — ROE 없이(중립값) 채점된 점수(D50) | 2026-11-26 22:3x | 9313ca0949fdb74c |
| `v3_scores_20261123.csv` | run 20261123 · 2,806행(v30·v32a) · 동결 2026-11-23 20:36:13 — 가치 점수 없이 채점(D48) | 2026-11-26 22:3x | 8ef1e674c65976aa |

왜: 11/26 배치가 11/23 의 ROE 칸을 뒤늦게 채워, `lowvol_score.py --run 20261123`·`--full` 을 돌리면 이 점수가 바뀐다(`research/handoff/REPLY_20261126b_roe_backfill.md`). DB 백업은 10일치만 남는다.
