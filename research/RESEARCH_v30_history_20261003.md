# 실제 v30 을 3년치로 다시 계산하면 — DART 과거 재무 PIT 재구성 (2026-10-03, 관측 · 1차)

> 재현: `python research/dart_history/collect_dart_history.py`(수집, 며칠) → `python research/dart_history/v30_history.py --validate`(검증) → `--start 20240102`(3년) → `python research/dart_history/v30_accumulate_3yr.py`(그림).

## 1. 무엇을 했나
- DART 과거 보고서(연간 2022~25 · 분기 2023~26)를 종목마다 받아 영업이익·영업현금흐름·자본·순이익만 저장(`dart_hist.db`). 1차는 **2,140/2,678종목**(DART 일일 한도 4만 건 → 나머지는 10/4 00:10 이후 자동 수집).
- 날짜 d 마다 "그때 알 수 있었던 보고서"만으로 3단계 지표(연간·분기 YoY·OCF·패턴)를 다시 만들고, 1단계 가격 지표(RSI·볼린저·스토캐스틱·52주 낙폭·반전 플래그·떨어지는 칼날)는 식 그대로 패널에서 벡터로 계산, `v3_rescore.rescore(SPEC_V30)` 를 **그대로 호출**해 점수를 냄.
- 보고서 가용일: DART 는 정정본이 있으면 정정 접수번호를 주므로(원본 접수일 소실) **접수일과 법정 마감일+10일 중 이른 것**을 가용일로 둠(근사).

## 3. 검증 — 2026-06-05~10-02 실제 적재(stage3_final·v3_scores)와 대조 (실측)
| 지표 | 일치 |
|---|---|
| RSI · 과매도 점수 · 1개월 수익 | 98~99% |
| 연간 YoY / 분기 YoY | 77% / 72% (수집된 종목만 보면 96% / ~92%) |
| 실적 패턴 / OCF 패턴 | 76% / 77% |
| 위험 등급 | 86% |
| 성분별(2026-07-06~, 실제 밸류 포함 재현): 반전·과매도 | 98% |
| 성분별: 품질 / 턴어라운드 / 가치 | 74% / 78% / **50%** (평균 −1.3점, DIV 0 때문이 큼) |
| **상위10 겹침**(날짜·시장당) | 재계산 2.5/10 → 실제 밸류 끼우면 3.8/10 → 실제 수급까지 끼우면 3.3~4/10 |
| 최종 점수 \|차이\| ≤ 5점 | 62% (평균 −5점, 재계산이 낮음) |

→ **가격 뼈대는 그대로 재현됐고, 재무는 수집된 종목에서 90%+ 재현됐으나, 상위 10 명단은 절반도 안 겹친다.** 상위권은 점수 차이 몇 점으로 갈리는데 배당·수급·위험등급·유니버스 차이가 거기서 작용한다. 따라서 3년 그림은 **"v30 의 가격·재무 뼈대(수급·배당 제외)"** 의 성적이지 실제 v30 의 성적이 아니다.

### 3-2. 2차 검증 — 수집 완료(2,678/2,678종목, 보고서 53,936행, 2026-10-04 00:33) 뒤
| 지표 | 기본 가용일(마감+10일 소급) | 엄격(접수일만) |
|---|---|---|
| 연간 YoY / 분기 YoY | **99% / 93%** | 95% / 92% |
| 실적 패턴 / OCF 패턴 | 97% / 98% | 94% / 96% |
| 위험 등급 | 86% | 86% |
| 최종 점수 \|차이\| ≤ 5점 · 평균 차이 | 74% · −3.7 | 72% · −7.2 |
| 상위10 겹침 | **3.5/10** | 3.4/10 |

→ 재무 재현은 거의 끝났다(1차의 불일치는 미수집 종목 때문). 그런데도 **상위 10 겹침은 3.5/10** — 남은 차이는 재무가 아니라 배당(DIV 0)·위험등급(공시 일부)·유니버스 컷·PBR/PER 근사·수급(검증에선 끼워 넣음)에서 온다. 즉 "v30 뼈대 ≠ v30"는 재무를 다 채워도 그대로다.

읽기: **수급·배당을 뺀 v30 뼈대는 3년으로 보면 시장을 못 이겼다**(2024년만 +1.1%p). 같은 패널의 가격4팩터(+11.4%p)·조용함(+2.4%p)과 대비된다.
단 §3 의 한계 그대로 — 실제 v30 과 상위10 이 2.5~3.8/10 만 겹치므로, "실제 v30 이 3년간 못 벌었다"가 아니라 **"v30 에서 재무·가격 부분만 떼어 보면 3년간 시장 수준이고, 2026 등록 후 성적(+3.8%p)은 수급·배당·그때 국면이 더해진 결과이거나 짧은 창의 운"** 둘 다 가능하다는 뜻이다.
가장 큰 빈칸은 수급(supply_score_v2) — v30 의 최근 성적에서 수급 항의 몫을 따로 재는 것이 다음 질문.

## 6. Codex 독립 검토(REPLY_007 §3) 반영 — 보고서 가용일
- 지적: `min(접수일, 마감+10일)` 은 정정본 접수일보다 과거에 보고서를 쓰게 함(30,700행 중 1,964행 소급, 중앙 89.5일) → 원본 당시 숫자가 확보되지 않은 상태에서 정정본을 소급하는 건 PIT 가 아님. 맞는 지적.
- 조치: `--pit-strict`(접수일만, 소급 없음) 옵션 추가. **민감도(실측)**: 연간 YoY 일치 77→74%, 분기 71→71%, 상위10 겹침 3.3→3.2/10, 점수 평균 차이 −5.1→−7.9 — 결론을 바꾸지 않는 크기. 엄격 쪽은 지연·정정 보고서를 늦게 보는 만큼 실제 3단계(캐시 시점 자료)보다 보수적이다.
- 근본 해결: DART 공시목록 API(list.json, 정기공시)로 **원본 접수일**을 받아 가용일로 쓰는 것 — 일일 한도 복구 뒤 2차 수집 후보. 전년동기 3개월 유도(`frmtrm_q_amount`)도 같은 문제(정정된 전년 금액) — 수집기에 `thstrm_dt`·`frmtrm_dt` 기간 문자열 저장 추가 예정.
