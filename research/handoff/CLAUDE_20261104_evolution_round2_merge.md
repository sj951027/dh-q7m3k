# Claude 메모 — 진화 검토 2차 대조·합치기 (Codex `REPLY_20261104_evolution_round2.md` vs 내 `research/REVIEW_20261103_fundamental.md`, 2026-11-04 아침)

> 두 의견은 같은 자료를 읽었으므로 일치가 독립 증거 둘은 아니다(Codex 도 같은 말). 아래는 **내가 받아들인 교정**, **다른 것**, **합친 '먼저 할 다섯'**, 그리고 **사용자 결정 거리**.

## 1. Codex 가 내 점검문에서 바로잡은 것 — 받아들임(8건)
1. **"좋은 모델 증거 없음(실측)"은 과했다.** 목적을 나눠 말해야 한다: 순위(IC)에선 lv_e 짝 우위가 실측 증거이고, 상위 바구니·계좌·집행(돈)에선 확증이 아직 없다. → 점검문 §0 문구를 그렇게 고친다.
2. **"창 시작일만 바꾸면 반나절"·"창 2개 통과면 해결"은 틀렸다.** 창별 계약(시작·종료·미완결 앵커 귀속·전체 판정 기회·오류 예산)을 먼저 동결해야 하고, 창을 계속 열다 통과한 것만 고르면 오류 기회가 는다. → 1-1 은 "굴러가는 창 자동화"가 아니라 **"다음 관측 계약 한 장"** 으로 바꾼다(Codex 1순위와 같음).
3. **돈 초과를 '표만 옮기면' 되는 게 아니다.** 지금 판정문 §2 의 돈 표는 h20·후보군 중앙값 대비·비용 없음이고, 운용 채택 잣대는 h40·같은 시장 전종목 대비·비용 0.5%. 다른 통계다. → 새 관측표를 같은 앵커 정의로 따로 만든 뒤 병기. "IC 유의인데 돈 0 품으면 승격 보류"는 **새 후보부터**(기존 모델엔 결과 뒤 조건 추가가 됨).
4. **10년 사전 검정 '4블록 중 3 양' 합격장은 채택 안 함.** 10년 DB 는 이미 여러 번 본 자료라 미열람 검증 자료가 아니고, 가격 성분만 가능해 편향된다. → "자료 자격 확인 → 고정된 추가가치 가설 → 제한된 반증 → 전향 검증" 단계(Codex 표)로 바꾼다. **to20 은 10년 DB 로 계산 불가**(shares 없음 — Codex 스키마 확인). ROE 제거 변형도 10년으론 못 한다.
5. **"청산 규칙이 없다"는 부정확.** 40일 만기 청산이 규칙이고, 손절은 지도 §6 에서 닫혀 있다. 없는 건 중도청산이며, 같은 자료에서 손절/익절 격자를 다시 찾는 건 우선이 아니다. → 청산 3장 보류. 새 근거가 있는 중도청산 가설 1건만, 소액 장부 뒤.
6. **MDE 를 CI 폭에서 "바로" 얻을 수 없다.** → "현행 CI 와 실용적 δ 의 관계를 적고 MDE 는 확인 못 함"으로. 검정력 모의시험은 별건.
7. **소액 사다리 (a) 는 변수 하나가 아니다**(시장별 10 → 전체 1위 · 보유 제외 · 5위 대체가 동시에 바뀜). 사용자 승인은 유지하되 "깨끗한 절제 비교"라고 부르지 않는다. 원인별로 말하려면 분해 표(원래 규칙 / 전체 1위만 / +보유 제외)가 따로 필요. (b)(c) 는 한 변수씩 맞음.
8. **결손일 설명 오류**: lv_e 초안 §0 "9/10·10/14 는 완결 표본에 영향 없음"은 틀렸다 — 9/10 은 h20 완결 앵커 범위(9/01~10/01) 안, 10/14 는 h10 범위 안. 관측이 없어 영향의 크기·부호를 모른다가 맞다. worklog 의 "10/30 가격은 h20 밖"도 앵커일과 종료가격일을 섞은 말. → 판정문 §0 문구 수정.
- 그 밖에 받아들임: 자리바꿈 통과율은 **어느 조건까지 묶었는지** 를 붙여 인용(h20+주별 25.3% → +Bonf 16.4% → +주블록 15.4% → +h10·짝 2.1%; 시총층 안에서는 0.05%) · 실적 원본은 "열 하나"가 아니라 버전 이력 계약 · 연구 결론에 상태/버전(정정된 옛 숫자가 큐에 살아 있지 않게) · 주문계획은 상태기계(재시도·부분체결·중복 적용 금지) · 제약 계좌는 다른 모집단을 산다(가격대·시장 이탈표).

## 2. 서로 다른 것(내 판단 유지 또는 보류)
- **국면**: Codex 는 "조건부 성적 차이 ≠ 조건부 매매의 이득" — 맞다. 나는 '발견'이라 했고 Codex 는 '가설'이라 한다. → **"국면 상호작용 가설"** 로 부르고, 고정된 E3(앵커일 코스피 A 여부·v30/lv_b·같은 투입액 대조)를 전향 관측으로. lv_e 로 바꿔 끼우면 새 가설(새 시작일).
- **basket10y 공통 모듈**: Codex 도 동의하되 "같은 라이브러리를 둘이 import 한 일치는 독립 검증이 아니다" → 운영 연구용 공통 구현 + Codex 는 독립 재구현. 사건 22개가 정답이 아니라 **정의를 먼저 고정하고 날짜 목록은 회귀시험용**. 유지(순서는 뒤로).
- **북극성 한 줄**: Codex 는 "B0 계좌 NAV 와 40일 바구니 초과는 다른 통계·트랙 비교 금지에 걸림" → 한 줄은 두되 **계좌 상태 한 줄**(기준일·정의·비용·현금 포함 여부 붙임)로, 운용 판정의 초과/CI 와 구분. 유지(표시 문구 수정).
- **앙상블**: Codex 는 "① 과매도∩저변동은 닫힌 '과매도 안 저변동'과 닮음, ② 순위 평균은 유니버스·척도 정리 선행, 둘 비교해 고르면 선택 단계 증가" → ① 안 함, ② 는 자격 심사(§1-4) 통과 뒤 한 후보로만. 보류.
