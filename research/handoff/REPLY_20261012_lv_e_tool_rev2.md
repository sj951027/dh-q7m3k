# lv_e 도구 보완 2 — 자리바꿈 백분위

작업일: **2026-10-11 KST**. 파일명의 `20261012`는 요청대로 유지했다. 수정한 파일은 `code_20261011_lv_e_verdict_tool.py`, 새 답변은 이 파일이다.

## 결과와 눈가림

**실측:** 가짜 메모리 DB에서 요청한 다섯 검증을 통과했다. 2,000회·seed 20261012로 시장 안 자리바꿈과 시총 5분위 감도를 구현했고, h20 단독 분포·통계 조건 통과율 및 h20·h10 짝차이를 출력한다. 기존 주 계산과 라벨·해석 함수는 바꾸지 않았다.

**실제 DB는 이번 작업에서 열지 않았다. `--real` 실행 0회.** 실제 점수·가격·수익·지속성·자리바꿈 결과를 계산하지 않았다. 수집기·배치·외부 호출·운영 코드·docs·worklog 수정·커밋·푸시 없음. 추가 중간 파일도 생성하지 않았다.

최신 작업 기록과 지정 `VERDICT_NOTE_20261011_power.md`에는 이미 판정한 창의 결과가 있어 읽었다. 금지된 리더보드 화면·텔레그램 기록·루트 `VERDICT_202610*_v30*.md`는 열지 않았다. Sol의 `code_20261012_placebo_null.py`는 정의·층·재표집 방법을 소스로 참고했으며 **import하거나 실행하지 않았다**. 새 계산은 기존 도구의 함수와 numpy·pandas·표준 라이브러리로 독립 구현했다.

## 구현 범위

- 자리바꿈은 **본 표·시장별 상관 평균·판정30** 경로에만 붙인다. 통합 상관·보충표 감도·다른 게이트의 기존 출력은 유지하되 그 조합의 자리바꿈은 생략한다.
- `placebo_prepare()`가 두 모델의 같은 등록 창에서 한 번이라도 나온 `(market,ticker)`의 **합집합**을 만든다. 미완결·게이트 제외 run의 출현도 이름표 모집단에는 포함한다. 실제 상관에 쓰는 run은 기존 게이트·앵커 중복 제거를 그대로 따른다.
- `placebo_draws()`가 시장 안에서 source→recipient **1:1 순열**을 뽑는다. 한 번 뽑은 순열을 전 날짜와 lv_e·lv_b 모두에 쓴다. 점수의 출현·결측 흐름도 함께 이동한다. recipient가 그날 원래 점수 대상일 필요는 없다. 자기 자신에 남는 일반 순열도 허용하고 고정 이름표 비율을 출력한다.
- 각 방식 **2,000회**, seed **20261012**다. 시장 안 전체와 시총 제한 방식 각각 같은 seed로 시작한다. 순열의 시도 번호는 두 모델·h20/h10에 공통이다.
- t+1 종가 진입, h20/h10 수익, 점프컷, pairwise 결측 제거 후 평균 동점 재순위, 시장별 8쌍·각 3고유값, 유효 시장 동등가중→유효 앵커 동등가중을 상속한다. 순열 전 identity 연결의 모든 앵커 값이 기존 주 계산과 일치하는지도 실행 중 검사한다(절대 오차 1e−12).

### 시총 감도

시총은 **등록일~자료 마감 안의 첫 유효 양수 close×shares**다. 현재 주식수를 과거 가격에 붙이지 않는다. 시장별 시총 평균 동점 백분위에서 `ceil(백분위×5)−1`로 0~4층을 만든다. 시총 결측은 참고 구현처럼 별도 6번째 층에서만 섞는다.

본 표 시세만 사용하며 보충표로 시총을 메우지 않는다. 동점 때문에 실제 층 수가 5보다 적을 수 있고, 한 종목뿐인 층은 이름표가 바뀌지 않는다. 시장별 전체 종목 수·시총 존재/결측 수·층별 크기·단독 종목 수를 출력한다. 첫 유효 시점은 종목마다 다르며, 당시 DB 스냅샷 복원이나 공통 기준일 시총을 뜻하지 않는다.

## 출력

### 분포·백분위

`render_placebo()`의 **‘각주 ④ 참고값 ③’**에 다음을 낸다.

| 항목 | 정의 |
|---|---|
| `quantiles` | 뒤섞은 앵커 평균의 **2.5·50·97.5 백분위**, 이 순서 |
| `actual_mean`, `actual_anchor_n`, `actual_iid95` | 같은 창·같은 주 계산의 관측 평균·n·iid95 |
| `percentile_le` | `100×P(뒤섞은 평균 ≤ 관측 평균)` |
| `percentile_midrank` | 동점의 절반만 넣은 위치: `100×(P(<)+0.5P(=))` |
| `lower_tail`, `upper_tail` | 동점 포함 아래쪽/위쪽 꼬리 비율. **관측값이 음수면 아래쪽을 읽음** |
| `two_sided_tail` | `min(1, 2×min(아래쪽, 위쪽))` |
| 꼬리의 `plus1` 값 | `(해당 꼬리 횟수+1)/(유효 시도 수+1)`도 따로 출력 |
| 시도 수·앵커 수 | 전체/유효/무효 시도 수, 시도별 유효 앵커 수 최소·최대 |

예를 들어 동일 모델의 짝차이가 전부 0이면 `≤` 위치는 100이지만 동점 중간값은 50, 두 꼬리 비율은 각각 1이다. 이를 우위 증거로 읽지 않도록 두 위치를 모두 낸다. 2,000회에서 초과 횟수 0도 참 확률 0의 증명이 아니다.

### 뒤섞은 점수의 ‘유의’ 비율

각 시도 h20 lv_e에 대해 기존 날짜·주 블록 재표집과 같은 **4,000회·seed 7**을 사용한다. 매 시도의 살아남은 앵커만으로 구간과 방향 비율을 다시 구한다. 주 블록은 뽑은 주의 모든 앵커를 이어 평균한다.

**구간 하단>0 + 방향≥60%**의 통계 조건 통과 횟수/전체 2,000회를 출력한다. 방향 정의는 기존 도구처럼 **앵커 기준·주 평균 기준을 병기**한다.

- 날짜 95%, 주 블록 95%, 둘 다 95%.
- **Bonferroni 11** 날짜 구간, 주 블록 구간, 둘 다 보정 구간.

상관을 전혀 못 구한 시도는 통과하지 않으며 그 수를 따로 낸다. 기존 40일 조건 미달이면 이 비율 칸은 비우고 ‘중간 관측’을 표시한다. 이 비율은 참고 문서의 **양(+) 통계 조건**에 관한 것으로, h10 재현·짝우위·커버리지·기존 고정 문턱까지 합친 최종 채택 라벨의 재현이 아니다.

### lv_b 짝비교

같은 순열 번호를 두 모델에 적용하고, **같은 앵커에서 lv_e−lv_b**를 계산한다. h20·h10 모두 기존 도구의 각자 종목 방식과 유효 공통 종목 교집합 방식으로 분포·관측 차이의 백분위·꼬리를 낸다. 공통 앵커 10 미만이면 선행 짝비교 규약에 따라 해당 시도의 평균은 산출하지 않고 무효 시도로 센다.

참고값은 별도 결과 객체이며 `legacy_label()`·`interpretation()`에 연결하지 않았다. 비교는 반올림 전 값, 반올림은 출력 단계뿐이다.

## 사용법과 한계

```powershell
# 기존 시험과 새 2,000회 자리바꿈 시험 모두 메모리 DB로 실행
python -B research/handoff/code_20261011_lv_e_verdict_tool.py --self-test
```

옵션 생략도 같은 가짜 자료 검증이다. 판정 날 `--real`을 실행하면 기존 결과를 먼저 출력하고 참고값 ③을 이어 계산한다. 약 5초 간격으로 경과 시간·처리 시도 수를 stderr에 출력하며 파일은 생성하지 않는다. 반복 중에도 기존 금지 시간 가드를 확인한다. **이번 작업에서는 `--real`을 실행하지 않았다.**

실제 자료에서의 값·실행 시간·메모리 사용량은 **확인 못 함**이다. 32회씩 나눠 순열·순위 계산을 하고, 같은 결손 패턴은 재표집 가중치를 공유해 계산량을 줄였다. 이는 재표집 분포를 다른 방식으로 바꾸는 근사가 아니다.

자리바꿈은 점수와 변동성·업종 등 종목 특성의 관계도 끊는다. 시총 층은 그중 한 특성만 일부 보존하고, 작은 층·시총 결측층에서는 교환 가능한 종목 수가 제한된다. 이 창의 경험분포를 다른 창의 성능이나 모든 효과 없는 모델의 오류율로 단정하지 않는다. 원천 시세·shares의 사후 수정과 적재 당시 상태도 **확인 못 함**이다.
