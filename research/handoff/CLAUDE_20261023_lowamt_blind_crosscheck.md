## 2. 차이 원인
1. **정리 수준**: 요청서 §2 정의에는 '거래대금 최하위 5% 제외'·'동전주 제외'가 없었다(Claude 가 관리종목 대리로 추가한 것). 같은 코드에서 이 둘을 빼면(S3) Codex 와 0.01%p 안으로 맞는다. 즉 최하위·동전주가 효과의 약 0.2%p 를 낸다.
2. **체결 한도 방식**: Claude 는 '거래대금 ≥ 주문×100' 인 종목만으로 표본을 새로 짜고 과매도·중앙값을 다시 정했다(= "유동성 있는 종목들 안에서도 한산한 쪽이 낫나"). Codex 는 전체에서 정한 아래 절반·과매도를 그대로 두고 양쪽에서 살 수 있는 종목만 남겼다(= "v32a 가 고른 종목 중 실제로 살 수 있는 것만 샀을 때 v30 대비 몇 %p"). **v32a 는 셀 전체 중앙값으로 자르므로 Codex 방식이 실제 운용 질문에 맞다.** → Claude 문서의 "종목당 1,000만원·참여율 1% 이면 뒤반 0" 은 "Codex 방식으로는 뒤반 +0.7(0 걸침), 300만원까지는 0 위" 로 고친다.
3. 작은 정의 차(0.1%p 안팎): Codex 는 t−20~t 가격 급변 신호 제외·동률을 아래 집단에 포함·2015-07 시작·정리매매 창을 따로 빼지 않음. 결론에 영향 없음.
