## 0. 한 줄 결론
- **해도 된다**(약관·안내에 자동주문 금지 없음, 오히려 대상 고객으로 명시). **알고리즘거래 등록제는 '회원전산센터에 둔 전용 주문시스템'이 요건**이라 집 PC·일반 인터넷 API 거래는 해당 없음(2차 인용 원문, 아래 A-3).
- **모의투자는 실제와 네 가지가 다르다**: ① 체결이 즉시가 아니라 실제 시장 체결이 생길 때(부분체결 있음) ② 원금 최소 1,000만원·기간 최대 3개월(만료마다 계좌번호가 바뀜) ③ 매도가능수량조회·휴장일조회·정정취소가능조회 등이 **모의 미지원** ④ 유량이 **초당 1건**(2026-04-20 기준) — 네 가지 모두 설계에 반영 가능하고, 막는 것은 없다.
- 새로 생긴 사용자 결정 2건: 모의 원금 1,000만원 중 300만원만 쓰는 상한(❓🔁) · 공개 docs 의 KIS 수급 열이 약관 제5조③에 닿는지(🔎).

### G. 보안
- 앱키 2종(실전 조회용·모의 주문용)은 `.env` 에 사용자만 넣는다(하드 경계). 토큰 발급 때마다 카톡 알림이 오므로 **예상 밖 발급 알림 = 유출 신호** → 즉시 해지·재신청(공지 2023-10-17).
- 제3자 위임 금지(A-2) → 집행 서버를 두더라도 본인이 운영하는 서버·본인 앱키. 키를 Claude·Codex 세션이 읽지 않는 규칙 유지(G3).
- 무한 재연결·과다 호출은 IP·앱키 차단 사유 → 재시도 상한은 보안 규칙이기도 하다.

### H. 사람·절차
- 모의투자 신청·재신청·API 신청은 **홈페이지 로그인**이 필요 → 사용자 직접(하드 경계). 달력 3개: 모의 만료(1~3개월) · Open API 1년 · 분기 리뷰(약관 변경·키).
- 모의 기간 선택은 **3개월**로(40거래일 3자 대조 + 여유). 만료 2주 전 재신청 → 새 계좌번호 → `.env`·장부 세대 갱신.
- B-7 공개 범위 문의는 사용자가 포털 '고객의 소리'로(문의 문구 초안은 요청 시 작성).

### I. PTW 자료 흐름 (계약 §17-2 보강점)
- PTW 는 v5.42 부터 **입출금 기록**(`/api/cashflows`: `date, amount, kind(deposit/withdraw/seed), memo`)을 가진다 → 대조표 `cash_diff` 를 설명하려면 체결 파일 외에 **입출금 파일**도 받아야 한다. 계약 v0 에 `ptw_cashflows_v0.csv`(같은 머리글 규약) 한 줄 추가 제안. 내보내기 API 는 아직 없음(읽기 API 만) → PTW 쪽 할 일 ⑤.
- PTW `GET /api/cron/backup`(토큰 보호)은 전 표(trades·sell_note·trade_label·cashflow 포함)를 JSON 으로 준다 → 사람이 CSV 를 내려받는 대신 **백업 JSON 한 파일**을 입력으로 쓰는 대안이 있다(열 이름은 DB 컬럼 그대로). 2단계 첫 2주 실측 때 어느 쪽이 덜 번거로운지 보고 고른다(❓🔁).

### J. 다른 증권사·대안 (조사 안 함)
- KIS 제약 중 설계를 막는 것이 없어 다른 증권사 모의투자 API 는 조사하지 않았다. 막히는 것이 생기면(예: 모의 원금 하한·3개월 재신청이 운영상 너무 번거로움) 그때 비교한다.
