# 데이터 주도 탐색 — 2026-10-04

사용자: 기존 조건 조합을 넘어 데이터에서 새로운 방법을 찾아 달라.

목적: 운영 모델 등록이 아닌 오프라인 탐색. 기존 §11·채택 기준은 변경하지 않는다. 조건 경계를 사람이 나열하는 대신 연속 지표 간 관계와 과거 경로의 유사성을 학습한다.

고정 사양(학습 결과 확인 전):
- 입력: 기존 자료의 149개 연속 지표 중 2024년 초기 학습에서 60% 이상 관측되는 열. 최근에만 있는 수급·기존 모델 점수 등을 과거로 채우지 않는다. 종목 코드·미래 수익은 입력하지 않는다.
- 평가: 2025년부터 분기별로 다음 구간을 예측한다. 각 분기 시작 전에 20일 결과가 끝난 과거 행만 학습한다(학습 신호일+20 < 평가 첫날). 시장별로 따로 학습한다. 현재 2026년 자료는 이미 다른 연구에서 봤으므로 완전히 새로운 시험 표본은 아니다.
- 지도 학습: 같은 고정 설정의 얕은 HistGradientBoosting으로 (1)20일 순수익≥20%, (2)첫날 상승, (3)20%+첫날 상승+최저 종가≥−10%+80%이상 진입가 위인 공동 사건, (4)20일 순수익 회귀를 각각 학습한다. 첫 셋의 평균 분위 순위도 별도 비교한다. 기간의 날짜별 종목 수 차이를 줄이기 위해 학습 가중치는 날짜당 동일하게 둔다.
- 비지도 학습: 과거 20일 가격·거래량 경로를 32개 군집으로 학습한다. 학습 자료에서 각 군집의 공동 사건 비율을 전체 비율 쪽으로 200건만큼 완화해 평가 기간의 군집 점수로 쓴다. 평가 기간 수익으로 군집을 고르지 않는다.
- 대조: 같은 날짜·시장·기록 가용 종목군의 평균, 거래대금 상위10, 연간 ROE/영업이익 증가 평균 순위 상위10, RSI 낮은10. 기존 운영 모델과 직접 순위 비교하지 않는다.
- 매일 상위10 예측을 평가. 목적별로 적중·첫날 상승·20일 수익·공동 사건·최저 수익과 날짜 수를 함께 표시한다. 계좌 수익이라고 부르지 않는다.
- 추가 진단: 분기별 유지·분류 점수의 신뢰도·같은 시총 구간 대조·선택된 종목 집중·거래대금순 대조와 짝지은 날짜 블록 구간. 40일 결과를 별도 확인한다. 좋아진 숫자만 보고 가중치/잣대를 다시 튜닝하지 않는다.
- 구현 검산과 원시 예측/선택 요약을 남긴다. 대용량 학습 중간 파일은 종료 후 정리한다.

고정 학습 설정: 트리 80회·학습률 0.06·최대 잎 15·최소 잎 관측 200·L2=10·조기 종료 사용 안 함(무작위 검증 혼입 방지). 군집은 MiniBatchKMeans 32개, 초기화 3회, seed=20261004. 이 설정의 최적화를 하지 않는다. 반환 수익 회귀는 제곱 오차를 사용한다. 설명용 얕은 나무는 예측기의 행동을 요약하는 용도이며 새 전략으로 평가하지 않는다.

사후 후속 가설: 초기 6개 학습 방식의 결과를 본 뒤 추가했다. 전체 랭커로서 재무 대조를 넘지 못하지만 첫날 상승 학습에 다른 장점이 보여, 재무 순위 상위50 안에서 first/joint/ret 예측으로 다시10개를 고른다. 후보 수는50으로 고정하며 여러 크기를 탐색하지 않는다. 기존 학습은 재학습하지 않는다. `hybrid_*` 결과는 결과를 본 뒤 설계한 탐색으로 별도 표시한다. 초기 사양이었던 것처럼 취급하지 않는다.
