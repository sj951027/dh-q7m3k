**상태**: **적용함(2026-11-27 밤 · D53)** — 사용자 "그렇게 적용". 실제로 한 것은 §2 의 권고안에 §2-3 '더 안전한 변형'(이력 절 제목 글자 그대로)이고, 결과는 15,000B → 13,758B(남는 자리 1,242B — 아래 §2-4 의 어림 1,700B 보다 적다: 절 제목이 새 요약보다 길어서). 아래는 적용 전에 쓴 제안 그대로다.
**기대(결과 전)**: 아래 권고안으로 자리 약 1,700B 가 난다고 본다 — 근거는 §0 의 줄별 크기(실측)에서 뺄셈한 것(추정).

## 2. 권고 = 나 + 다 + 번호 풀어 쓰기 (가 는 D41 대로 12월 판정 뒤 P19 에서)

이유: 자리는 '가'와 비슷하게 나면서 **옛 결정 문장을 한 글자도 다시 쓰지 않는다.** 대기 목록은 결정이 아니라서 결정 장에 꼭 있을 이유가 약하고, 사용자가 말한 "기록장을 여러 개로 나누기"에 그대로 맞는다.
